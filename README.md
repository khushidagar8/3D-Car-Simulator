
# 3D Car Simulator

A beginner-friendly 3D car driving simulator built using Python and Panda3D.

## Features
- 3D car body and wheels
- Keyboard-based driving controls
- Steering, acceleration and braking
- Speedometer
- Day and night mode
- Headlights
- Follow camera

## Requirements
- Python
- Panda3D

## Installation
Install Panda3D:

    py -m pip install panda3d

## Run the Project
Run the Python file:

    py car_project.py

## Controls
- Up Arrow: Accelerate
- Down Arrow: Brake / Reverse
- Left Arrow: Steer left
- Right Arrow: Steer right
- Space: Brake
- N: Toggle day and night
